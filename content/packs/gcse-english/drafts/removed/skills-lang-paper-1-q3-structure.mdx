## Key steps (method)

- Track the extract’s **journey**: where it starts, what changes, and where it ends.
- Pick 2–3 structural features:
  - shifts in focus/setting
  - zoom in/out
  - contrasts
  - pace changes (sentence lengths)
  - withholding/revealing information
- For each feature: explain **why it’s placed there** and its effect on the reader.
- Use a simple timeline (start → middle → end) so you cover the whole extract.

## Common mistakes

- Analysing language instead of structure.
- Listing features with no purpose/effect.
- Only writing about the first few lines.
- Calling everything a “cliffhanger” without justification.
