## Key steps (method)

- Use a timeline: **start → shift → end**.
- Pick 2–3 structure ideas from:
  - shift in focus/setting
  - zoom in/out
  - pace changes (sentence length)
  - contrasts
  - withholding/revealing information
  - cyclical ending
- For each, write: **what changes → where → why → effect on reader**.

## Common mistakes

- Analysing language instead of structure.
- Listing features with no purpose.
- Only writing about the first few lines.
