## Key steps (method)

- Read the question carefully: identify the **theme/focus** you must compare.
- Write a one-sentence **comparison thesis** (both similarity + difference).
- Plan 2–3 comparison points (each point compares **both** poems).
- For each point: choose one short quote from each poem.
- Compare methods + meanings (AO2): imagery, tone, structure shifts, perspective.
- Use comparative connectors naturally: **whereas, similarly, in contrast, both, however**.

## Common mistakes

- Writing two separate mini-essays (Poem A then Poem B) with little comparison.
- Only comparing ‘themes’ and ignoring language/structure.
- Using lots of quotes but analysing none of them.
- Forgetting to link back to the question focus throughout.
