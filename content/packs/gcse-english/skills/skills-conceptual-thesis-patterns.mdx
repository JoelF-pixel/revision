## Key steps (method)

- Start with a concept, not a character: **power, guilt, responsibility, identity, control, love**.
- Use one of these thesis patterns:
  - **Tension:** *Although X seems…, ultimately…*
  - **Journey:** *At first…, but as…, the writer suggests…*
  - **Critique:** *The writer uses X to expose/criticise…*
  - **Dual reading:** *X can be read as…, yet it also…*
- Make sure the thesis answers the question wording.

## Common mistakes

- Writing a thesis that’s just a description (“Macbeth is ambitious”).
- Trying to sound clever but not answering the question.
- Forcing multiple interpretations into the thesis without evidence.
