## Key steps (method)

- Use precise verbs for analysis: **suggests, implies, conveys, exposes, undermines, reinforces**.
- Use cautious judgement language: **arguably, perhaps, could be read as**.
- Prefer meaning-rich nouns: **power, guilt, morality, responsibility, identity, conflict**.
- Keep it honest: only use a term if you can explain it in plain English.

## Common mistakes

- Overcomplicating sentences until the meaning disappears.
- Using buzzwords with no link to the quote.
- Repeating the same phrase (“This shows…”) every paragraph.
