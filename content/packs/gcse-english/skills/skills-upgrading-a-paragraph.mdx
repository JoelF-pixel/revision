## Key steps (method)

- Start with: point + quote + basic explanation.
- Upgrade 1: add **AO2 zoom** (one key word + connotations).
- Upgrade 2: add **structure** (contrast/shift/pattern) if it’s relevant.
- Upgrade 3: add **purpose** (what the writer wants the audience to think/do).
- Upgrade 4 (optional): add a **second interpretation**.
- Final check: link back to the question in the last line.

## Common mistakes

- Adding fancy words instead of better analysis.
- Throwing in context without linking it to the quote.
- Making the paragraph longer but not sharper.
