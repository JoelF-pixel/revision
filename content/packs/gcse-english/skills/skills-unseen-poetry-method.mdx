## Key steps (method)

- Read once for **what happens** + the speaker’s attitude.
- Identify the **big idea** (theme) and the emotional journey (start → shift → end).
- Annotate a handful of high-impact words + 1–2 structural choices (turns, contrasts, repetition).
- Plan 2–3 paragraphs:
  - Point about meaning
  - Evidence
  - AO2 zoom-in (methods + effect)
  - Link to overall message
- If there’s a comparison question, build each paragraph as a **compare point** (both poems each paragraph).

## Common mistakes

- Panicking and trying to analyse every line.
- Technique spotting with no meaning.
- Ignoring structure (the shift/turn is often the key).
- Writing vague effects (“makes it interesting”).
