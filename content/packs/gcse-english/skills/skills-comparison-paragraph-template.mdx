## Key steps (method)

- Start with a **comparison point** (similarity + difference).
- Quote from **Poem A**, zoom in (AO2), explain meaning.
- Immediately quote from **Poem B**, zoom in (AO2), explain meaning.
- Compare effects using: **whereas / similarly / in contrast / this suggests**.
- End by linking back to the theme in the question.

## Common mistakes

- Doing Poem A then Poem B with no direct comparison.
- Comparing only themes and ignoring methods.
- Forgetting to link to the question.
