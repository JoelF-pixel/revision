## Key steps (method)

- Pick **short, high-impact** quotes (2–8 words) rather than long chunks.
- Prefer quotes with **clear word choices** you can zoom in on (verbs/adjectives/images).
- Use 1 quote per paragraph, then analyse it properly.
- If you can, choose evidence that links to **writer’s purpose** (AO3-ready).

## Common mistakes

- Picking a quote you can’t explain (then you waffle).
- Using loads of quotes with no analysis.
- Choosing only “obvious” plot quotes instead of writer’s choices.
