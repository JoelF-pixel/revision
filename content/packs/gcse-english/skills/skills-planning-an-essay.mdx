## Key steps (method)

- Re-read the question and underline the **focus** (theme/character/relationship/idea).
- Write a **one-sentence thesis** answering the question (your overall argument).
- Choose **3 points** (often 3 paragraphs) that each support the thesis.
- For each point: pick **one strong quote** + 2 mini-zoom notes (word choice / method / effect).
- Add 1 AO3/context note only if it **directly supports** the point.
- Decide your paragraph order: usually strongest point first, or a logical journey.

## Common mistakes

- Planning lots of ideas but not a clear argument (becomes a list).
- Picking quotes you can’t analyse (too general, no methods to zoom in on).
- Bolting context on at the end of a paragraph rather than linking it to meaning/purpose.
- Making the plan so long you run out of writing time.
