## Key steps (method)

- Turn the question into a **judgement** (not a description). Use: *Ultimately… / Priestley/Shakespeare presents… to…*
- Add **tension/complexity**: show an argument that can handle counterpoints ("however", "although").
- Build a paragraph spine: **claim → evidence → method → effect → meaning → writer’s purpose → link back to judgement**.
- Use **alternative interpretations** where natural (same quote, different readings).
- End with a conclusion that strengthens the judgement (don’t just repeat).

## Common mistakes

- Writing a vague thesis (“Shakespeare shows Macbeth is ambitious”) with no judgement or purpose.
- Forcing multiple interpretations that aren’t supported by the language.
- Making AO3 the main point (it should support AO1/AO2, not replace them).
- Sounding ‘fancy’ but not actually answering the question.
