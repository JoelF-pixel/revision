## Key steps (method)

- Start with **meaning from the text first** (AO1/AO2), then add context to deepen it.
- Use context as a “because”:
  - *This matters because… (Jacobean beliefs / Victorian society / post-war politics)*
- Link context to **writer’s purpose** (what are they criticising / warning / promoting?).
- Keep context specific and relevant (one sharp sentence beats a mini-history lesson).

## Common mistakes

- Dumping context at the end of a paragraph with no connection to the quote.
- Being vague (“back then women had no rights”) without linking to the moment in the text.
- Getting context wrong or mixing time periods (e.g. confusing 1912 vs 1945 for AIC).
- Making AO3 the main point and forgetting to analyse the language.
